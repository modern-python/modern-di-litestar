# modern-di-litestar 2.11.0 — modern-di 2.21.0 floor + connection-mapping cleanup

Maintenance release. **No public API change** — `ModernDIPlugin`, `FromDI`, `build_di_container`, and the context providers keep their signatures and behavior. It raises the `modern-di` floor and single-sources an internal.

## Internal refactors

- **Connection-kind mapping single-sourced off the context providers.** `build_di_container` no longer re-states each connection type and context key in an `isinstance` ladder; it walks the registered context providers (`_CONNECTION_PROVIDERS`), taking each `context_type` and `scope` from the provider. The plugin registers from the same tuple. Adding a connection kind is adding a provider — behavior is unchanged (`Request` → `REQUEST`, `WebSocket` → `SESSION`).

## Packaging

- **`modern-di` floor raised to `>=2.21.0,<3`** (was `>=2.20.0`). The refactor relies on the public `ContextProvider.context_type` added in modern-di 2.21.0.

## Upgrade

Bump `modern-di-litestar` to `2.11.0`; `pip`/`uv` will pull `modern-di>=2.21.0`. No code changes required.

## Internals

- 100% line coverage across Python 3.10–3.14; `ruff` and `ty` clean.
- Added direct unit tests for the `FromDI` dispatch seam; stable release tags now require curated notes.
